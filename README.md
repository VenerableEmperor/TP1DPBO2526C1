## DESIGN CLASS
Program memiliki satu kelas yaitu film seperti yang sudah dispesifikasikan, dengan atribut :  
* ID : Sebagai pengenal utama setiap objek dalam class film 
* NAMA : Untuk judul film
* GENRE : Untuk genre film
* HARGA : Untuk harga satu tiket film
* JUAL : Untuk seberapa banyak tiket sudah terjual
